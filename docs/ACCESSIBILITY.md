# Accessibility

- Native input, select, button, and dialog elements are used for interaction.
- Slash focuses the search input; Escape clears it when search has focus and closes a native dialog when appropriate.
- Creature cards have descriptive accessible names and independent save buttons.
- Save buttons expose their toggle state using aria-pressed.
- Search result counts are announced using a polite live region.
- The global motion control uses aria-pressed and respects prefers-reduced-motion.
- Visible focus outlines support keyboard users.
- Rarity and habitat labels are readable text, not color-only information.
