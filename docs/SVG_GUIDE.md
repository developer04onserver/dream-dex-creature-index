# Creature SVG authoring

## Requirements

Save each file under public/creatures/<id>.svg. Use a 160 by 160 viewBox and a descriptive title and description referenced by aria-labelledby. Keep resources local: no network images, remote fonts, scripts, or linked CSS.

## Animation

Use declarative animate and animateTransform for gentle floating, wing movement, blinking, or glow. Keep transitions calm. Do not use rapid flashes or strobing. Always make the static pose recognizable.

## Review checklist

- [ ] Unique silhouette and creature name
- [ ] Palette matches its habitat
- [ ] Accessible title and description
- [ ] No external dependencies
- [ ] Gentle animation and static fallback
- [ ] Legible at card size
- [ ] Catalogue metadata updated
